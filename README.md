# QA Automation Trainee — Technical Task

## About

This repository contains my solutions to the technical task for the QA Automation Trainee position at Andersen.

## Task 1 — Python

The `main.py` script implements the following requirements:

- Prints `Hello` if the entered number is greater than 7.
- Checks whether the entered name is `John` and prints the corresponding message.
- Accepts a sequence of numbers separated by spaces and outputs the numbers divisible by 3.

## How to Run

1. Make sure Python 3 is installed.
2. Open a terminal in the project directory.
3. Run the following command:

```bash
python main.py
```

Follow the prompts and enter the requested values.
